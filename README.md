# Юрмани — статический каталог

Главная страница — index.html. Поиск, фильтры и подборки работают в браузере на основе products.json. В карточках кнопка «Запросить цену у менеджера» открывает текст запроса с названием товара, который клиент копирует и отправляет в MAX.

Для локальной проверки выполните `python -m http.server 8000` из корня репозитория и откройте http://localhost:8000/. После правок products.json запустите `python tools/build_seo.py` и добавьте обновлённые страницы в коммит.

Для публикации в GitHub Pages выберите Settings → Pages → Deploy from a branch → main → /(root). Файл CNAME содержит основной домен юрмани.рф. Проверьте настройки домена и HTTPS в GitHub Pages перед переключением DNS. Действующие настройки DNS хранятся в REG.RU.
