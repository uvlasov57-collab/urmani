# Юрмани — сайт и каталог

Статический сайт для текущего домена, указанного в `CNAME`. Новые файлы размещаются в корне репозитория. Файл `.nojekyll` сохраняется при публикации через GitHub Pages.

## Локальная проверка

В этой папке выполните:

```sh
python -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000`. Для телефона в той же сети используйте текущий IPv4 компьютера и тот же порт.

## Обновление ассортимента

Источником названий, категорий, цен и фотографий остаётся `products.json`. После его изменения выполните:

```sh
python tools/build_seo.py
```

Опубликуйте изменившиеся `products/`, `categories/`, `seo-data.js`, `sitemap.xml`, главную и каталог вместе с исходными данными. Адреса товаров формируются из их ключей и изображения; изменение имени или изображения может изменить адрес.

## Что подготовлено

- 1096 отдельных страниц товаров и 26 страниц разделов, включая страницы продолжения и список разделов.
- Карта сайта на 1124 адреса, заголовки, описания, canonical, ссылки между страницами, разметка Organization, Product, ItemList и BreadcrumbList.
- Категории и товары читаются без JavaScript. Интерактивный каталог сохраняет фильтры и пять подборок с подразделами.
- Товар из отдельной страницы попадает в ту же заявку. Кнопка копирует заявку и открывает профиль MAX; вставка и отправка остаются за покупателем.

## Пределы разметки и проверки

У товара показана цена из прайса. Единицы продажи, фасовка и наличие требуют подтверждения менеджером. В разметке не выдуманы остатки, отзывы, рейтинги и единицы цены. Merchant Offer не добавлен до подтверждения этих данных; показ расширенных товарных результатов Google не обещается.

После публикации нужно проверить домен, отправить sitemap в Яндекс Вебмастер и Google Search Console и запросить проверку ключевых страниц. Доступ к этим кабинетам и фактическая индексация не проверены в локальной сборке. Настройки источника публикации GitHub Pages нужно сохранить действующими.
